# RIM Lab Website

Official website of the Robotics and Intelligent Mechanisms Lab (RIM Lab), Department of Mechanical Engineering, Sogang University.

- Framework: Next.js 14 + Tailwind CSS (TypeScript)
- Content lives in `content/*.ts` (news, publications, team, projects, videos) — edit those files to update the site.
- Deployed on Vercel; production domain: rim.sogang.ac.kr (to be connected).

## Development

```bash
npm install
npm run dev
```
